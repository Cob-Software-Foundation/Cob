Verify your download

Every release includes a checksums.txt. Confirm what you downloaded before you run it.

1
Download checksums.txt

It sits alongside the binaries on the same GitHub release.

2
Hash the file you downloaded

Use sha256sum (Linux/macOS) or Get-FileHash (Windows PowerShell).

3
Compare

The hash should match the line for your file in checksums.txt exactly.

# Linux / macOS
$ sha256sum cob-linux-amd64.tar.gz
$ grep cob-linux-amd64 checksums.txt

# Windows (PowerShell)
> Get-FileHash cob-windows-amd64.zip -Algorithm SHA256
