Cob is a small corn-themed language with an interpreter, a native compiler, and a package manager — built to boot fast, compile to a real standalone binary, and stay out of your way.

One toolchain, three jobs

Each tool does exactly one thing — run a file, build a binary, or fetch a library — and hands off cleanly to the next.

cob_interp file.cob

Interpret

Runs a .cob file directly, with a fast-boot .strawberry bytecode cache so repeat runs skip re-parsing.

popcorn_comp file.strawberry -o out

Compile

Transpiles to C and spawns a real compiler to produce a standalone native binary — cross-compile with CobOS/CobArch.

farmer harvest name

Fetch

Installs a .cob library from the package registry, zip-slip protected, ready to shuck straight into your program.

Recent history

0.0.4 Strings, and pop() that can finally print a variable

Cob variables were integers only since the language's first release. This adds strings: pop(<expr>) accepts any expression instead of only a literal, "+" concatenates, and ==/!=/</>/<=/>= work on two strings the same way they already did on two numbers. Shipped in both cob_interp and popcorn_comp — a compiled binary behaves identically to the interpreted program, including matching type-mismatch warnings.

0.0.3-bug-fix-2 Project moved to the Cob-Software-Foundation GitHub org

All three repos (Cob, cpi, and the new Cob-Docs) now live under Cob-Software-Foundation instead of pixel-pulse-labs. Every hardcoded repo/registry URL was updated, including farmer's default package registry (COB_FARMER_DEFAULT_BASE_URL), so a plain `farmer harvest <package>` resolves correctly without setting $COB_FARMER_BASE_URL by hand.

0.0.3-bug-fix-1 popcorn_comp: fixed a Windows-only cmd.exe quoting bug

Auto-resolving a bundled zig/ folder next to popcorn_comp could produce a compiler command cmd.exe corrupted before it reached the shell. Explicit --cc/$CobCC compiles were never affected.

0.0.3 Project Obsidian Falcon

popcorn_comp dropped its embedded TCC in favor of spawning a real compiler (Zig by default); farmer moved to in-process zip extraction with zip-slip protection; SQLite, Tcl, and Tk vendored (not yet wired into the language).
