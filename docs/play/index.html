Play with Cob

A real build of cob_interp, compiled to WebAssembly, running entirely in this tab. Nothing is installed and nothing is sent anywhere — edit the script on the left, hit Run, and read the output on the right.

This is the stripped-down cob_interp core — no SQLite, no Tcl/Tk, no _cobwindow, and no native extern libraries (a browser tab can't dlopen() anything). A script that uses any of those keywords still runs: they quietly do nothing and print a one-time notice, so the rest of your script keeps going. Want the full thing? Download the native build for real windows, databases, and C extensions.
