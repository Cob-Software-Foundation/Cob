Play with Cob

A real build of cob_interp, compiled to WebAssembly, running entirely in this tab. Nothing is installed and nothing is sent anywhere — edit the script on the left, hit Run, and read the output on the right.

This is cob_interp built for the browser. A tab can't dlopen() a shared library, so the standard library modules that can run in a browser (porch, cornmath, kernels, almanac) are compiled into it and shuck loads them as usual. The ones that need a real computer — pantry (SQLite), barn (windows), tassel (Tcl/Tk), granary (files) — and any native extern library quietly do nothing and print a one-time notice, so the rest of your script keeps going. porch_ask() and porch_ask_int() ask with a browser dialog (a tab has no keyboard to read); press Cancel and the program sees the end of its input. Want the full thing? Download the native build for real windows, databases, files, a REPL, and C extensions.
